# ALLBLACK Phase 2 — Arabic Localization

Arabic localization for ALLBLACK Phase 2 (Ren'Py 7.3.5.606), using Modern Standard Arabic, Noto Sans Arabic, right-to-left layout, Arabic text shaping, and corrected RTL slow-text timing.

## Installer

Run `ALLBLACK-Phase-2-Arabic-Setup.exe`, select the folder containing `ALLBLACKPhase2.exe`, and choose Install. The installer makes a timestamped backup before copying the Arabic files. Uninstall restores the backup when available.

## Scope

The payload contains the translated Phase 2 dialogue and UI, compiled Ren'Py translation files, Noto Sans Arabic, and the RTL runtime support patch. Original audio, images, and game scripts are not redistributed.

## Verification

All translated files compiled successfully with the bundled Ren'Py engine. Structural validation reported zero errors; the translation audit was retained with the localization work files for review.
